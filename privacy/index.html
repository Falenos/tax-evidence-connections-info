Privacy Policy

Last updated: October 10, 2026

Purpose

This application helps users organize user-selected records and communications.

Google data accessed

With user authorization, the application may access selected Google Drive file metadata and content, and relevant Gmail message metadata, content, labels, and attachments. It may organize selected files and labels when requested by the user.

Use, storage, and sharing

  • Google data is used only to provide user-requested record organization.
  • Google data is not sold, used for advertising, or shared with third parties.
  • Google data is not used to train generalized artificial-intelligence models.

Security and retention

Reasonable safeguards are used to protect authorized data. Records are retained only as needed for the requested purpose and can be deleted by the user. Access can be revoked at any time through Google Account connections.

Google API policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy , including its Limited Use requirements.
